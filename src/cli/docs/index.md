# qtcloud-knowl CLI 参考

## 这是什么

一个**知识库质检员**。不帮你写知识，而是检查已有知识库的结构问题。

**全面体检（audit）**：检查整个知识库，出一份报告。标记 **【需人确认】** 的项目由你拍板。

**自动抽取（extract）**：从 Markdown 文档中创建知识库骨架，按内容推荐所属领域。配置大模型后可启用语义抽取。所有 AI 产出需审核后入库。

## 典型场景

| 你想做什么 | 平台做什么 | 你需要做什么 |
|-----------|-----------|-------------|
| 刚建好知识库，想知道有没有问题 | 运行全部检测，分组输出 | 处理文件缺失和 JSON 错误，确认术语冲突 |
| 存量知识库定期体检 | 审计全部领域，标记新增问题 | 关注新增 **【需人确认】** 项 |
| 术语定义混乱，想排查 | audit 自动标记未定义术语和引用断裂 | 逐一确认每个冲突项 |
| 拿到一批新文档要入库 | extract 扫描文档、推荐领域、创建骨架 | 审核领域归属，补充本体和实例 |
| 交接知识库给新人 | audit 输出完整报告 + 问题清单 | 新人按清单逐项修复 |

## 人机分工

| 你来做 | 工具来做 |
|--------|----------|
| 决定用哪个视角看知识 | 按你选的视角自动检查 |
| 确认术语冲突怎么处理 | 列出所有冲突术语 |
| 审核 AI 抽取的内容 | 从文档提取候选知识 |
| 判断本体抽象是否到位 | 按标准自检，标记存疑项 |
| 决定跨领域关系是否存在 | 推荐候选关系 |

## 命令参考

详细命令说明见 [commands.md](commands.md)。

| 命令 | 说明 |
|------|------|
| `audit` | 全量质量审计 — 串行执行全部检测，聚合输出可读报告 |
| `extract` | 从 Markdown 文档创建知识库骨架，按内容推荐所属领域 |

| 环境变量 | 说明 |

| `QTCLOUD_KNOWL_LLM_API_KEY` | LLM API key（extract 需要） |
